# Visual asset and texture licenses

The 3D scene currently uses procedural Three.js geometry, built-in materials, and generated star points. It contains no downloaded planet textures, 3D models, or shader image assets.

| Asset | Source and license |
|---|---|
| `public/next.svg` | Default Next.js starter logo SVG. Next.js source is MIT licensed; see [vercel/next.js LICENSE](https://github.com/vercel/next.js/blob/canary/license.md). The Next.js name and logo remain trademarks of Vercel. |
| `public/window.svg`, `public/file.svg`, `public/globe.svg` | Default Next.js starter interface SVGs, distributed with the MIT-licensed Next.js starter source; see [vercel/next.js LICENSE](https://github.com/vercel/next.js/blob/canary/license.md). |
| `public/vercel.svg` | Default Vercel starter triangle SVG. No separate asset license is stated in the file; Vercel branding is a trademark and this file is retained only as the unmodified starter asset. |
| `src/app/favicon.ico` | Project favicon. No external source or license metadata is present in the repository; provenance is currently undocumented. |

There are no third-party texture or model assets in `src/components/3d`. Scene colors, primitive meshes, and the point starfield are generated by project code. Lucide icons are imported from the `lucide-react` package instead of copied as standalone image assets; the package is ISC licensed (see [Lucide license](https://github.com/lucide-icons/lucide/blob/main/LICENSE)).
